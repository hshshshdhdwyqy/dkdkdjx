# NRT Self | سلف تلگرام

NRT Self، سلف تلگرام (Telethon) با ساعت زنده کنار اسم، بات مدیریت، پنل دکمه‌ای، ابزارها و امنیت.

## قابلیت‌ها
- 🕒 ساعت زنده کنار اسم: `𝟷𝟺 : 𝟶𝟾` (وقت تهران)
- 🤖 **دو بات**: بات مدیریت + بات هلپر (پنل)
- 🤖 **بات مدیریت**: `/start`، اطلاعات اکانت، فعالسازی با شماره + کیبورد دکمه‌ای کد ورود، خاموش/روشن/حذف سلف
- 🎛 **بات هلپر**: پنل دکمه‌ای inline با `.پنل`
- 🟢 حالت آنلاین، منشی، اکشن، حالت متن
- 🧰 هوا، ارز، کریپتو، ترجمه، ماشین‌حساب، هوش مصنوعی، متن به ویس
- 👥 تگ اعضا (`.همه`، `.تگ 20`)، حذف پیام، بن/سیک/آنبن، پین/حذف پین، بن سراسری
- 🎮 تاس، دارت، بولینگ، بسکتبال، کازینو
- 🎙 متن به ویس (مرد/زن)، ویس به متن
- 🎵 آهنگ، سرچ یوتیوب، کیفیت عکس
- 🔁 ابزار تبدیل: عکس/ویدیو/گیف/استیکر/دایره به همدیگه
- 🎮 **بازی گروهی روی بات هلپر**: بلک‌جک ۲۱ (۲–۳ نفره یا با ربات) و دوئل تاس با سکه‌ی مجازی، موجودی، جایزه‌ی روزانه، جدول برترین‌ها
- 🫂 لیست دوستان با پاسخ خودکار، 📦 محتوای ذخیره‌شده با کلمه‌ی میانبر
- 🔒 قفل پیوی، بلاک، سکوت، فیلتر کلمات، ضد لاگین، بکاپ چت
- ⚡ سین خودکار، پاسخ خودکار، ری‌اکشن خودکار
- 🆕 پرفیکس، جوین از پیام، عضویت اجباری، کامنت اول، نگهبان چت، دانلود، اسکرین سایت، مدیریت گروه، تقلب، چالش استارزی، بازی گربه (پایین README)

لیست کامل دستورها: `.راهنما`

## قبل از نصب
1. از https://my.telegram.org بخش API development tools یه `API_ID` و `API_HASH` بگیر.
2. آیدی عددی خودت رو از @userinfobot بگیر (`OWNER_ID`). فقط همین آیدی می‌تونه از باتا استفاده کنه.
3. توی @BotFather دو تا بات بساز (هر دو لازمن):
   - **بات مدیریت** (`MANAGER_BOT_TOKEN`)
   - **بات هلپر** (`HELPER_BOT_TOKEN`): بعد از ساختن، `/setinline` بزن و بات رو انتخاب کن.
4. (اختیاری) عکس بنر خودت رو با اسم `assets/banner.jpg` بذار تا توی `/start` بات مدیریت نشون داده بشه.

## گذاشتن روی گیت‌هاب
```bash
cd telegram-self
git init && git add . && git commit -m "init"
git branch -M main
git remote add origin https://github.com/USER/REPO.git
git push -u origin main
```
`.env`، سشن‌ها و دیتابیس‌ها توی `.gitignore` هستن و آپلود نمی‌شن. ریپو رو **Private** بساز.

## نصب سریع روی VPS
```bash
git clone https://github.com/YOUR_USER/YOUR_REPO.git
cd YOUR_REPO
bash install.sh
```
`install.sh` اول می‌پرسه سلف شخصی (۱) یا هاب + پنل وب (۲)، بعد API_ID، آیدی عددی خودت، آیدی گروه بازی و توکن‌ها. توی حالت ۱: بعد توی بات مدیریت `/start` بزن ← «فعالسازی سلف» ← شماره‌ت رو با دکمه بفرست ← کد ورود رو با کیبورد دکمه‌ای وارد کن (اگه رمز دومرحله‌ای داری، رمز رو بنویس).

> کد ورود رو هیچ‌وقت توی چت تایپ نکن؛ تلگرام باطلش می‌کنه. فقط با کیبورد دکمه‌ای بات.

اگه بات مدیریت نمی‌خوای، توکنش رو خالی بذار تا لاگین از ترمینال انجام بشه (`python self_bot.py --login`).

## ⚠️ هشدار
- فایل `.env` و `*.session` مثل پسورد اکانتتن؛ هیچ‌وقت روی گیت‌هاب نذارشون (توی `.gitignore` هستن).
- استفاده از سلف ممکنه خلاف قوانین تلگرام باشه و ریسک محدودیت اکانت داره. مسئولیتش با خودته.

## نکته‌ها
- ابزار تبدیل، ویس و آهنگ به `ffmpeg` نیاز دارن (`install.sh` نصبش می‌کنه).
- آهنگ/یوتیوب با `yt-dlp` کار می‌کنه؛ بعضی IPهای VPS رو یوتیوب بلاک می‌کنه.
- «ویس به متن» اول از ترنسکرایب خود تلگرام (پریمیوم) استفاده می‌کنه و اگه نبود از SpeechRecognition.
- «کیفیت عکس» بزرگ‌کردن + شارپ معمولیه، نه هوش مصنوعی.

## بازی گروهی
**گروه بازی:** توی `.env` مقدار `GAME_CHAT_ID` رو آیدی عددی گروه بذار (مثل `-1001234567890`؛ چندتا رو با کاما جدا کن). نصب‌کننده (`install.sh`) هم همین رو ازت می‌پرسه. اگه خالی بذاری بازی‌ها توی همه‌ی چت‌ها کار می‌کنن. بعد از تغییر: `systemctl restart telegram-self`.
بات هلپر رو توی گروه اضافه کن (فقط خودش، نیازی به ادمین نیست). دستورها: `/21 [شرط]`، `/dice [شرط]`، `/balance`، `/daily`، `/top`، `/games`.
برای دستورهای فارسی بدون اسلش («بازی 21»، «موجودی»...) توی BotFather بزن `/setprivacy` ← Disable.
سکه‌ها مجازین (شروع با ۱۰۰۰، جایزه‌ی روزانه ۵۰۰) و هیچ خرید، فروش یا انتقالی ندارن؛ موجودی‌ها توی `games.db` ذخیره می‌شه.

## 🏢 حالت هاب چندکاربره (فروش سلف / چند نفر با یه بات)
اگه می‌خوای به‌جای یه سلف شخصی، یه بات بدی دست چند نفر که هرکدوم سلف خودشون رو با شماره‌ی خودشون فعال کنن
(مثل سلف‌سازهای فروشی با الماس و تست رایگان)، به‌جای `self_bot.py` این‌ یکی رو اجرا کن:

```bash
python hub.py
```

- هر کاربر با `/start` روی **بات هاب** (`HUB_BOT_TOKEN`) وارد می‌شه، شماره‌شو می‌ده، کد ورود رو با کیبورد وارد می‌کنه
  و سلفِ خودش (پروسه‌ی جدا، مستقل از بقیه) بالا میاد.
- هر کاربر جدید همون اول **۶ ساعت تست رایگان** می‌گیره (`TRIAL_SECONDS`)؛ بعدش فقط با **الماس** می‌تونه سلفش رو روشن نگه داره.
- موجودی الماس هر کاربر با گذشت زمانِ واقعی کم می‌شه (نرخ با `DIAMOND_SECONDS`، مثلاً هر الماس = نیم ساعت) و وقتی صفر بشه
  سلفش خودکار خاموش می‌شه و بهش پیام می‌ده.
- **پنل ادمین**: آیدی خودتو (و هر ادمین دیگه‌ای) تو `ADMIN_IDS` بذار؛ با `/start` یا `/admin` روی همون بات هاب وارد پنل می‌شی:
  - 👥 لیست همه‌ی کاربرا (با وضعیت روشن/خاموش) + جستجو با آیدی یا یوزرنیم (`جستجو 12345`)
  - روی هر کاربر: ➕ افزایش الماس، ➖ کاهش الماس، 🎁 هدیه‌ی ۶ ساعت تست، 📨 پیام تکی، ⛔/✅ بن و رفع بن، خاموش‌کردن سلفش
  - 💎 **الماس همگانی**: یه مقدار بده، به همه‌ی کاربرا اضافه می‌شه
  - 📢 **پیام همگانی**: یه متن بده، برای همه‌ی کاربرا فرستاده می‌شه
- اگه `HUB_HELPER_BOT_TOKEN` رو هم بدی (با `/setinline` فعالش کن)، دستور `.پنل` همه‌ی کاربرا از همون یه بات هلپر مشترک کار می‌کنه.
- سشن و کانفیگ هر کاربر جدا و توی `hub_sessions/` و `hub_configs/` ذخیره می‌شه؛ این دو پوشه هم باید مثل `.env` محرمانه بمونن.

> این حالت جایگزین بات مدیریت تکی (`manager.py`) هست، نه مکملش؛ برای هاب چندکاربره نیازی به `MANAGER_BOT_TOKEN` نیست.

## 🆕 قابلیت‌های تکمیلی (الهام‌گرفته از LTM Self)
این‌ها تو `extras.py` هستن و خودکار به `self_bot.py` وصل شدن (نیاز به تنظیم جدا نداره):

- 🗡 **دشمن**: `تنظیم دشمن` / `حذف دشمن` / `لیست دشمن` / `پاکسازی لیست دشمن`؛ و لیست فحش با
  `تنظیم فحش [متن]` / `حذف فحش [متن]` / `لیست فحش` / `تنظیم لیست فحش` (ریپلای فایل txt).
  وقتی یکی از لیست دشمن‌ها بهت پیام بده، خودکار (با فاصله‌ی ۶۰ ثانیه) یه فحش رندوم از لیست جوابش می‌ره.
- 📣 **تبچی (بنر تبلیغاتی خودکار)**: `تبچی روشن/خاموش`، `وضعیت تبچی`، `لیست بنر ها`،
  `تنظیم بنر فور` یا `تنظیم بنر کپی` (با ریپلای روی پیام موردنظر ثبت می‌شه)، `حذف بنر N`،
  `پاکسازی لیست بنر ها`، `تنظیم دقیقه بنر [دقیقه] [N]` (فاصله‌ی ارسال)، `تنظیم گپ هدف بنر N` /
  `حذف گپ هدف بنر N` (گپ فعلی رو اضافه/حذف می‌کنه)، `تنظیم هدف بنر N` (برای همه‌ی گروه‌ها)،
  و `فور بنر در [تعداد]` (با ریپلای؛ به N تا پیوی اخیرت فوروارد می‌کنه).
- 💥 **اسپم**: `اسپم [متن] [تعداد]` یا با ریپلای `اسپم [تعداد]` — حداکثر ۳۰۰ بار.
- 📸 **اسکرین صفحه**: `اسکرین صفحه [تعداد]` یه عکس شبیه‌سازی‌شده از آخرین پیام‌های چت (حباب چت) می‌سازه.
  با `اسکرین صفحه روشن` حالت خودکار فعال می‌شه: وقتی طرف مقابل تو پیوی بنویسه «اسکرین صفحه»،
  پیامش پاک و عکس چت برات فرستاده می‌شه. تعداد پیش‌فرض با `اسکرین صفحه تعداد [۳ تا ۳۰]`.
  > برای نمایش درست حروف فارسی تو عکس، `install.sh` فونت Vazirmatn رو خودکار دانلود می‌کنه.
- ⭐ **استارزی (پست خودکار روزانه)**: `تنظیم عکس استارزی` (با ریپلای محتوا رو ثبت می‌کنه)،
  `تنظیم زمان استارزی HH:MM`، بعد `استارزی روشن` — هرروز همون ساعت، همون محتوا توی همون گپ پست می‌شه.
  > این یه پست زمان‌بندی‌شده‌ی ساده‌ست، نه محتوای واقعی پشت‌پولی استارز تلگرام (که زیرساخت جدا می‌خواد).
- 🔴 **لایو**: `لایو [عنوان]` یه پیام وضعیت می‌سازه، `پخش [لینک/اسم]` یا با ریپلای به صف اضافه/پخش
  می‌کنه، `مکث`/`ادامه`/`بعدی`/`صف`/`قطع`، `جلو [ثانیه]`/`عقب [ثانیه]`/`برو [ثانیه]`، و
  `پنل لایو` یه پنل دکمه‌ای (از طریق بات هلپر) برات می‌فرسته.
  > این یه **پخش‌کننده‌ی صف‌دار ساده**‌ست (فایل بعدی رو می‌فرسته و پیام وضعیت رو ویرایش می‌کنه)،
  > نه استریم واقعی صدا/تصویر به تماس گروهی تلگرام؛ اون قابلیت به کتابخونه‌ی جدای `pytgcalls` و
  > زیرساخت صوتی/WebRTC نیاز داره که این پروژه نداره.

## ادمین نامحدود و پنل وب (hub.py)

- هر آیدی که توی `ADMIN_IDS` باشه موجودی الماس **نامحدود** داره: سلفش هیچ‌وقت خاموش نمی‌شه و الماسش کم نمی‌شه.
  توی منوی ادمین دکمه‌ی «🤖 سلف خودم» هست تا سلف خودت رو فعال کنی.
- پنل وب: توی `.env` مقدار `WEB_PASSWORD` رو بذار و `python hub.py` رو اجرا کن، بعد `http://127.0.0.1:8080` رو باز کن.
  امکانات: آمار کلی، لیست و جستجوی کاربران، افزایش/کاهش الماس، تست هدیه، بن/رفع بن، خاموش‌کردن سلف کاربر، پیام تکی و همگانی، الماس همگانی.
- پیش‌فرض فقط روی خود سرور گوش می‌ده. از بیرون با SSH tunnel (`ssh -L 8080:127.0.0.1:8080 user@server`) یا پشت nginx/caddy با HTTPS باز کن (و `WEB_SECURE=1` بذار).

## 🆕 قابلیت‌های نسخه‌ی ۳ (هم‌ترتیب با منوی LTM Self)
این‌ها توی `more.py` هستن و خودکار به `self_bot.py` وصل شدن. پنل (`.پنل`) هم الان ۸ صفحه‌ست و همین ترتیب منوی LTM Self رو داره.

> عمداً **اضافه نشدن**: ایموجی پریمیوم، ایموجی پریمیوم چنل، کارخونه میوی، میو خودکار، پیشی خودکار و ماهی‌گیری خودکار.

- 🔣 **پرفیکس**: `.پرفیکس /` پیشوند دستورها رو عوض می‌کنه (۱ یا ۲ نماد). `.پرفیکس پیش‌فرض` برمی‌گردونه.
  اگه یادت رفت چی گذاشتی، دستور `.پرفیکس پیش‌فرض` با نقطه همیشه کار می‌کنه.
- 🔗 **جوین از پیام**: `.جوین` (ریپلای روی پیامی که لینک `t.me/...`، لینک دعوت `+xxxx` یا `@یوزرنیم` داره؛ حداکثر ۱۵ مورد).
- 📢 **عضویت اجباری** (توی گروه): `.عضویت اجباری تنظیم @channel` یکبار، بعد توی هر گروه `.عضویت اجباری روشن/خاموش`.
  پیام کسایی که عضو کانال نیستن پاک می‌شه و یه هشدار موقت میاد. (باید توی گروه ادمین با دسترسی حذف پیام باشی؛ ادمین‌ها و بات‌ها معاف‌ان.)
- 🥇 **کامنت اول خودکار**: `.کامنت اول افزودن @channel`، `.کامنت اول متن اول 🔥|زود اومدم` (چندتا با `|` جدا کن، رندوم انتخاب می‌شه)،
  `.کامنت اول روشن/خاموش`، `.کامنت اول حذف @channel`. با هر پست جدید اون کانال‌ها، اولین کامنت رو می‌ذاره (کانال باید گروه بحث داشته باشه).
- 🛡 **نگهبان چت** (توی گروه): `.نگهبان روشن/خاموش` و `.نگهبان لینک|فوروارد|منشن|استیکر|گیف روشن/خاموش`.
  پیام غیرادمین‌ها طبق نوع‌های فعال پاک می‌شه.
- 🧰 **کاربردی**: `.آیدی`، `.تاریخ` (شمسی + میلادی)، `.یادآوری 30 دقیقه متن` (به Saved Messages می‌فرسته)،
  `.لیست یادآوری`، `.پاکسازی یادآوری`، `.لینک پیام` (ریپلای)، `.ذخیره` (ریپلای ← Saved Messages).
- ⬇️ **دانلود**: `.دانلود لینک` یا `.دانلود صدا لینک` (یا ریپلای روی پیام لینک‌دار). با `yt-dlp` کار می‌کنه
  (یوتیوب، اینستاگرام عمومی، توییتر، تیک‌تاک، ...) و لینک مستقیم فایل هم تا ۲۰۰ مگابایت. آدرس‌های داخلی/localhost بلاک‌ان.
- 🌐 **اسکرین سایت**: `.اسکرین google.com`. بدون لینک، `.اسکرین` مثل قبل اسکرین چت می‌گیره. (از سرویس عمومی thum.io استفاده می‌کنه.)
- 🛠 **مدیریت گروه** (ادمین باش): `.مدیریت گروه` لیست دستورها، `.قفل گروه`، `.بازکردن گروه`، `.عنوان گروه`، `.توضیحات گروه`،
  `.لینک گروه`، `.ترفیع`، `.عزل`، `.اخراج` (ریپلای یا آیدی)، `.لیست ادمین`، `.حالت آرام 30`.
- 🎯 **تقلب**: `.تقلب تاس 6` — تاس/دارت/بولینگ/بسکتبال/فوتبال/کازینو رو تا رسیدن به عدد دلخواه می‌فرسته و بقیه رو پاک می‌کنه (حداکثر ۱۵ بار).
- 🔥 **چالش استارزی**: `.چالش استارزی روشن 30` — بعد از تنظیم استارزی، هر پست روزانه با «روز X از N» ارسال می‌شه و آخرش خودکار خاموش می‌شه.
- 🐱 **بازی گربه**: `.بازی گربه بگیر [اسم]`، `غذا`، `بازی`، `خواب`، `اسم X`، `وضعیت`، `ریست`. سیری/شادی با گذشت زمان کم می‌شه.
  (یه مینی‌بازی ساده‌ی داخل خود سلفه؛ به هیچ بات بیرونی وصل نیست.)

### توی هاب چندکاربره (`hub.py`)
- 💎 **انتقال الماس**: هر کاربر از منوی بات هاب «💎 انتقال الماس» ← آیدی/یوزرنیم گیرنده (باید توی بات /start زده باشه) ← مقدار ← تایید.
  ادمین‌ها موجودی نامحدود دارن و از این قابلیت استفاده نمی‌کنن؛ همه‌ی انتقال‌ها توی جدول `transfers` ثبت می‌شن.
- 👮 **مدیریت ادمین**: توی پنل ادمین دکمه‌ی «👮 مدیریت ادمین». **مالک‌ها** (آیدی‌های `ADMIN_IDS`/`OWNER_ID` توی `.env`) می‌تونن ادمین اضافه/حذف کنن؛
  ادمین‌های معمولی فقط لیست رو می‌بینن. ادمین‌های اضافه‌شده توی دیتابیس (`admins`) می‌مونن.

### 🔧 رفع باگ
- هوک «دشمن» و «اسکرین خودکار» (`extras.py`) قبلاً هیچ‌وقت صدا زده نمی‌شد و کار نمی‌کرد؛ الان وصل شد.
- دکمه‌های «اطلاعات/پینگ» توی پنل مشترک هاب دیگه خطا نمی‌دن.
